# Paritet Cosmetic Web

## Назначение
Frontend-часть проекта Paritet Cosmetic на Next.js.

## Статус
Текущая версия ориентирована на desktop-экраны.
Мобильная версия будет реализована отдельным этапом.

## Доступ
- Онлайн-демо: пока не опубликовано.

## Технологии
- Next.js
- React
- TypeScript
- Tailwind CSS

## Переменные окружения
Используется файл `.env.local` на базе `.env.example`.
Секреты и реальные ключи в репозиторий не добавляются.

## Примечание
Этот README описывает только frontend-модуль `apps/web`.
