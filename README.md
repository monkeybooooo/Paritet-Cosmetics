# Paritet Cosmetic

## Краткое описание
Paritet Cosmetic — desktop-first сайт-визитка компании-поставщика косметической продукции. Проект оформлен как портфолио-кейс с акцентом на визуальную композицию главного экрана и аккуратную презентацию бренда.

## Статус проекта
Проект находится в разработке.
На текущем этапе реализуется desktop-версия сайта.
Мобильная версия планируется как отдельный этап, так как текущая визуальная концепция использует крупные изображения и композицию, рассчитанную на широкий экран.

Текущая версия оптимизирована для просмотра на desktop-экранах.

## Используемые технологии
- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS (утилитарные классы + глобальные стили)

## Реализованные возможности
- Главная страница с крупным визуальным блоком (hero section)
- Верхняя навигация
- Выпадающее меню каталога
- Базовые страницы каталога (структура в `app/catalog/...`)
- Подключение локальных графических ассетов из `public/`

## Инструкция по запуску
1. Перейти в папку фронтенда:
   ```bash
   cd apps/web
   ```
2. Установить зависимости:
   ```bash
   npm install
   ```
3. Запустить проект в dev-режиме:
   ```bash
   npm run dev
   ```
4. Открыть в браузере:
   [http://localhost:3000](http://localhost:3000)
